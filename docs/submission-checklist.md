# Hackathon submission checklist

Confirm current official hackathon requirements before submitting; this checklist intentionally does not invent platform rules.

- [ ] Public HTTPS demo URL is available and opens without reviewer login.
- [ ] Demo URL works in a private/incognito browser.
- [ ] Two-minute-or-less video is uploaded or linked.
- [ ] Project summary is under 250 words.
- [ ] Repository link is public and points to the submission branch.
- [ ] Teammate details/emails are supplied if the official form requires them.
- [ ] Synthetic-data and independent-prototype disclosures are visible.
- [ ] OpenAI live-path status is represented honestly.
- [ ] No secret or local evidence is committed.
