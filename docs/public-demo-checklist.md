# Public demo checklist

- [ ] URL opens over HTTPS.
- [ ] No login is required.
- [ ] Sample case works.
- [ ] No broken assets or browser errors appear.
- [ ] Recommendation works.
- [ ] Action package works.
- [ ] Mobile layouts work at 360, 390, and 412 pixels.
- [ ] Prototype label is visible.
- [ ] No secret, local path, or debug output is visible.
- [ ] Nothing claims a complaint or message was sent.
