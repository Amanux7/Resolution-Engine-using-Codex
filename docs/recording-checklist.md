# Recording checklist

- [ ] Use a clean browser profile with notifications disabled.
- [ ] Hide bookmarks, personal tabs, local paths, and private information.
- [ ] Start from the Resolution Engine home screen at normal zoom.
- [ ] Confirm **Try a sample case** opens the fictional walkthrough.
- [ ] Confirm the recommendation and action package paths work.
- [ ] Use the optional live extraction only if it was pre-checked successfully.
- [ ] Ensure no API key, environment file, prompt, or developer output is visible.
- [ ] Check cursor visibility and microphone/audio.
- [ ] Keep the final recording below two minutes.
